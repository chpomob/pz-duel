# F7 — Robustesse du cadrage HTTP et sémantique des arguments Lua

commit: fix(phase1): F7 — Robustesse du cadrage HTTP et sémantique des arguments Lua

## Contexte

Troisième vérification : A6 tient sur les identifiants et sur l'encodage, `mini_lua` tient (le
balayage a été éprouvé par mutation : retirer `remove=_remove` fait échouer 10 tests). Deux
défauts restent, dont un nouveau majeur qui appartient à la même famille que A6 : une entrée
textuelle peut encore provoquer une exception sans réponse JSON.

## Constats à corriger

### NEW [major] — `Content-Length` peut interrompre la réponse avant tout contrôle
`service/api.py:97,103,138` : une longueur positive dépassant `Py_ssize_t` est acceptée par
`int`, puis provoque `OverflowError` dans `read`, avant même le contrôle `Host` et sans
interception. Exemple : `POST /api/action` avec `Content-Length: 9223372036854775808`.

**Correction attendue** : fermer la classe « en-tête de cadrage hostile ». Le corps n'est lu
qu'après validation d'une longueur bornée (chiffres uniquement, plafond explicite de taille de
corps, rejet de 0 sur une action qui en exige un), avec un refus JSON explicite (400 ou 413) et
sans jamais appeler `read` sur une valeur non validée. Le gestionnaire de requête ne doit plus
pouvoir sortir par une exception non rattrapée : une dernière barrière transforme tout imprévu en
réponse JSON, sans fuite de trace. Tests : longueur démesurée, longueur négative, longueur non
numérique, corps vide, et un test qui prouve que le refus intervient avant toute lecture.

### NEW [minor] — `math.floor`/`math.ceil` refusent les arguments supplémentaires
`tests/doubles/mini_lua.py:436,564` : `pcall(math.floor, 2.7, 0)` échoue en `TypeError` avec le
double, alors que Lua ignore l'argument supplémentaire et rend `true, 2`. Même défaut pour `ceil`.

**Correction attendue** : les fonctions du double acceptent les arguments supplémentaires et les
ignorent, comme Lua le fait pour ces fonctions ; la conversion en entier et les cas infini/NaN
restent ceux déjà en place. Test : `pcall(math.floor, 2.7, 0)` → `true, 2`, idem `ceil`, et
`math.floor` sans argument échoue comme Lua.

## Règles

- Ne touche qu'à ces deux constats.
- Un test de régression par constat, qui échoue sans le correctif ; pour le cadrage, le test doit
  prouver l'absence de lecture, pas seulement l'absence de plantage.
- `.venv/bin/python -m pytest -q` doit rester vert (962 tests actuellement, 5 skips) en moins de 90 s.
- Python stdlib uniquement ; messages en français.
- Un seul commit, sujet : `fix(phase1): F7 — Robustesse du cadrage HTTP et sémantique des arguments Lua`.
- Réponse finale en français : constat par constat, mécanisme corrigé, test ajouté.
